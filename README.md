# DIARABILWE-MOPHUTING-ST10478218-WED5020-POE
Webpage for Rayton Home Bakery

The webpage in this project is that of Rayton Home Bakery. It showcases the bakery, its products, menu, specials, gallery, and contact details through the use of HTML and CSS.
The styles in the CSS were created using the concepts and properties mentioned in the Web Development & Design PDF.
Files of the Project
index(1).html – The HTML webpage
style.css – External CSS file
rayton_home_bakery_with_css.html – The HTML webpage with CSS styles included in the webpage

Mobile-first web design
Running the Webpage
Save index(1).html and style.css files in the same directory.
Open index(1).html in a browser.
The webpage will get styles from the style.css file.
The HTML file links the CSS file using the code below:

<link rel="stylesheet" href="style.css">
